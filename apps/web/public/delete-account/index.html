FretFlow 계정 및 데이터 삭제

FretFlow 계정 소유자는 웹과 Android 앱에서 직접 계정 삭제를 요청할 수 있습니다.

삭제 요청 방법

  1. 아래 계정 삭제 시작 버튼을 누릅니다.
  2. 삭제할 계정으로 로그인합니다.
  3. 표시되는 삭제 화면에서 안내를 읽고 DELETE를 입력합니다.
  4. Permanently delete account를 누릅니다.

삭제되는 데이터

  • 계정 프로필과 로그인 세션
  • 서버에 동기화된 악보와 연습 데이터
  • 공유 링크와 이용 권한 정보
  • 클라우드 음원 기능이 활성화된 경우 연결된 업로드 파일

기기에 남을 수 있는 데이터

브라우저나 앱에만 저장된 악보와 녹음은 서버 계정과 별도이므로 자동으로 지워지지 않을 수 있습니다. 라이브러리에서 삭제하거나 Android 설정에서 FretFlow의 저장공간·앱 데이터를 삭제해 제거할 수 있습니다.

법률상 보존 의무 또는 보안·분쟁 대응에 필요한 최소 기록은 관련 법령에서 정한 기간 동안 분리 보관될 수 있습니다.
